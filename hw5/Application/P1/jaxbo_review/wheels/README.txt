This directory must contain the audited hw5-bo-simulator-runtime 0.2.0 binary
wheels supplied with the assignment. The supported release targets are:

- CPython 3.12 on Windows x86-64
- CPython 3.12 on manylinux x86-64
- CPython 3.12 on manylinux ARM64
- CPython 3.12 on macOS Apple silicon

Do not place a source archive or a pure-Python runtime wheel here.
